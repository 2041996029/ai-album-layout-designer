# ai-album-layout-designer
面向摄影师／影楼与个人的 AI 相册排版设计工具。首期网页完整编辑，微信小程序快速成册，为 App 预留接口。

支持方向：多页相册、33 种滤镜、文字／形状／模板、AI 智能排版、水墨彩绘、账号会员与 AI 点数、在线权益、导出队列。

当前阶段为研发评审与实施计划，用户已确认全程 AI 开发，尚未开始产品代码实施。

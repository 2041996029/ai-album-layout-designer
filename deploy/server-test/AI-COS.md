# AI 与腾讯云 COS 测试接入

此版本增加 OpenAI Images 兼容适配器与腾讯 COS 官方 SDK。未提供真实密钥，未调用付费接口，也未验证真实供应商可用性。供应商声明“兼容 OpenAI”不保证支持图片编辑或图像审核；这些能力必须分别验证。普通相册排版和文字编辑不调用生图接口。

## 升级数据库

备份现有数据库与对象存储后，在已有 005 的数据库执行 `006_ai_runtime.up.sql`，使用 `psql -v ON_ERROR_STOP=1 -f ...`。新增表与索引在一个事务内创建。不要重放 001、不要删除卷。空数据库的 Docker 初始化已包含 006；现有卷不会自动执行新增初始化文件。

## 腾讯云 COS

将 `.integrations.env.example` 中的 COS 字段填入服务器私有 `.integrations.env`。桶须为私有读写，服务账号仅授予所需桶和前缀权限。旧配置版本和本地对象定位仍保留，切换桶不会把旧对象错误指向新桶；跨服务器迁移仍须搬迁旧对象并保留相应读取配置。

## OpenAI 兼容服务

填写 AI 域名白名单、审核服务、审核与标识策略版本。凭据通过已有版本化秘密存储读取，不能把密钥放到前端、GitHub Pages、提示词或模型描述。`AI_IMAGE_EDITS_ENABLED` 默认关闭；只有供应商已验证支持时才打开。审核失败或无法确认时，不发布图片。

代码运行时绑定会检查上述依赖。真实可用的模型、预设、商业授权、报价规则和配置发布仍须完成管理流程；设置环境变量本身不会自动创建已验证模型。现阶段后台的模型管理与实际样本测试发布流程尚未全部完成，因此不要将本开发分支视为完整 C5/C6 发布版本。

## 已实现的行为

- 报价不扣点；接受报价时原子预占点数、存储空间与供应商预算，预算日为上海时区。
- 同一报价重复接受不会创建第二个任务；接口受理状态未知时只查询原任务，不重复提交。
- 参考照片须明确授权并固定任务资源引用；结果下载受 HTTPS 白名单、内容类型、大小、像素和哈希检查约束。
- 审核通过后写入带 AI 标识的原图、规范图与预览图，并保留来源链与供应商原始输出哈希。用户取消与成功竞态通过租约和 fence 决定能否发布。
- 失败释放用户点数；已发生的供应商费用仍计入采购预算。兼容接口不返回真实账单时采用冻结的估算成本，不能当作供应商结算证据。

真实联调需提供供应商模型、授权依据、审核能力和预算审批，以及 COS 桶、地域和服务账号。通过服务器私有配置提供密钥，不要在聊天中发送。支付、AI、真机、备份恢复与容量准出仍需各自证据，不能用回放测试代替。

# C2 整本排版、局部重排与照片完整性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可解释且可撤销的整本分配、固定跨页构图、有效候选比较和真实文档完整性校验。

**Architecture:** 使用确定性的两层引擎：先解整本容量／顺序，再在固定页框匹配模板。候选及manifest与真实DocumentModel双向核对，应用是基于revision的一次文档命令；云端应用复用同一验证器。

**Tech Stack:** C1 TypeScript工作区、Vitest、React、Playwright；纯CPU规则引擎，无外部生图依赖。

**Spec:** [v0.3 §§4–5／10](../../design-v0.3/README.md)、[PRD §6](../../ai-album-v0.1/02-产品需求文档.md)、[v0.4](../../configuration-v0.4/04-配置清单与验收.md)、[C1接口](2026-10-21-c1-editor-render.md)。

> 实施完成记录：[C2 验证与评审结果](../../implementation/c2/README.md)。下方步骤已执行；历史计划中的预期不是独立验收证据，实际结果以实现记录为准。

## Global Constraints

- 本文是待执行研发计划；测试片段和预期结果均不是当前已通过记录。只写本模块实现；真实微信、存储、支付、AI集成缺凭据时保持 `unconfigured`，本地模拟／契约测试可完整实施。
- 继承 [共同合同](../../release-v1.0/CONTRACT-RULES.md)：公开ID为1–128字符不透明字符串；SHA-256为64位小写十六进制；金额为人民币分整数、点数整数，JSON整数上限9007199254740991；UTC存储，展示和预算日为Asia/Shanghai。
- API根 `/v1`；成功 `{data,requestId}`，失败 `{error:{code,message,retryable,details},requestId}`；列表 `{items,nextCursor,hasMore}`。网页cookie＋CSRF，小程序短期bearer；所有资源逐次校验工作区权限。
- 可重放创建／财务／任务操作使用空间范围唯一的 `Idempotency-Key`，保留7天；相同key不同payload返回409。文档If-Match revision为字符串；草稿／目录更新有expectedRevision／If-Match，冲突409。
- 唯一产品文档模型由C1 `@album/document`提供，对应 `document.schema.json`；schemaVersion1、px96、sRGB；1–50内页跨页、500照片、100递归图层／跨页、组深度≤5。原片JPEG／PNG≤25_000_000字节且≤80MP；不接受任意外部URL素材引用。
- 平台统一存储／AI连接，不开放BYOS／BYOK；免费与付费能力都实现，真实价格／配额未经确认不得伪造。影楼首期单使用者，预留owner/admin/designer/viewer与seat_limit，不做邀请UI；App仅预留共享API。
- 测试命令沿用C1 `npm run test:unit -- <file>`／`npm run test:browser -- <file>`、`npm run typecheck`。集成测试使用临时PostgreSQL／Redis和本地受控模拟，禁止生产数据库；精确依赖版本在实施时锁入package-lock.json，Node 24 LTS。
- 默认 `selectionPolicy=all`、`duplicatePolicy=forbid`；只有allowSelection或明确列入repeat许可的照片可改变分配；每个输入照片必须在placements或unused中可核对。
- 推荐3个有效候选；不足3个展示真实数量，不用无效候选凑数。硬约束满足率100%；视觉候选可接受率≥80%是未来盲评目标，不能充当已测结果。
- 12张／4跨页／每页2–4张可行；50张／10跨页／每页最多2张无解，返回至少25跨页，不静默删片。
- 普通排版不调用生图、不消耗AI点数；主体分析仅服务当前项目，不建立跨项目人脸身份库。

## Review Focus

- RF1：无EXIF、同时间、用户明确顺序和重复内容但不同assetId应保留稳定顺序，不默默折叠；任务1／2有断言。
- RF2：锁定框已超容量、锁定照片未在选片范围与局部重排的外部照片应产生可解释冲突，不偷改锁定；任务2／4有断言。
- RF3：极端横竖比例、0／NaN几何及图库行布局超高不能以评分掩盖固定页越界；任务3有断言。
- RF4：manifest宣称完整但真实文档漏片或混入装饰用途时不能应用／导出；任务4有断言。
- RF5：候选计算时用户编辑、网络重试与取消不能覆盖新revision或应用两次；任务5／6有断言。

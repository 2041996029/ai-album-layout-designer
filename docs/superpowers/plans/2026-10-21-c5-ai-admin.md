# C5 AI创作、模型内容版本与运营后台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付有许可和用途确认的AI艺术素材，从能力验证／报价预算到异步生成、审核标识、私有入库、可编辑标题入册与运营后台。

**Architecture:** 供应商能力与模型／路由／预设均不可变版本化，报价固定输入和费用合同。接受任务在C4同一数据库事务预占点数／预算并入队，输出先隔离校验和审核标识再入素材库，成功终局才结算；网页和mini只使用已发布能力。

**Tech Stack:** TypeScript、C3 API与PostgreSQL、C4 jobs／credits／config、Node隔离下载、供应商adapter、React web/admin、Vitest／Playwright；不采用非商业Zine Skill。

**Spec:** [v0.3 §§2／7](../../design-v0.3/README.md)、[AI服务配置](../../configuration-v0.4/03-AI服务与模型配置.md)、[配置验收](../../configuration-v0.4/04-配置清单与验收.md)、[PRD GEN-01/02](../../ai-album-v0.1/02-产品需求文档.md)、[provider合同](../../release-v1.0/contracts/schemas/provider.schema.json)。

## Global Constraints

- 本文是待执行研发计划；测试片段和预期结果均不是当前已通过记录。只写本模块实现；真实微信、存储、支付、AI集成缺凭据时保持 `unconfigured`，本地模拟／契约测试可完整实施。
- 继承 [共同合同](../../release-v1.0/CONTRACT-RULES.md)：公开ID为1–128字符不透明字符串；SHA-256为64位小写十六进制；金额为人民币分整数、点数整数，JSON整数上限9007199254740991；UTC存储，展示和预算日为Asia/Shanghai。
- API根 `/v1`；成功 `{data,requestId}`，失败 `{error:{code,message,retryable,details},requestId}`；列表 `{items,nextCursor,hasMore}`。网页cookie＋CSRF，小程序短期bearer；所有资源逐次校验工作区权限。
- 可重放创建／财务／任务操作使用空间范围唯一的 `Idempotency-Key`，保留7天；相同key不同payload返回409。文档If-Match revision为字符串；草稿／目录更新有expectedRevision／If-Match，冲突409。
- 唯一产品文档模型由C1 `@album/document`提供，对应 `document.schema.json`；schemaVersion1、px96、sRGB；1–50内页跨页、500照片、100递归图层／跨页、组深度≤5。原片JPEG／PNG≤25_000_000字节且≤80MP；不接受任意外部URL素材引用。
- 平台统一存储／AI连接，不开放BYOS／BYOK；免费与付费能力都实现，真实价格／配额未经确认不得伪造。影楼首期单使用者，预留owner/admin/designer/viewer与seat_limit，不做邀请UI；App仅预留共享API。
- 测试命令沿用C1 `npm run test:unit -- <file>`／`npm run test:browser -- <file>`、`npm run typecheck`。集成测试使用临时PostgreSQL／Redis和本地受控模拟，禁止生产数据库；精确依赖版本在实施时锁入package-lock.json，Node 24 LTS。
- 规则排版／文字编辑不消耗AI生图点数；textSuggestion为首期RESERVED/OFF，路由不能启用、公开图片GenerationInput不能报价文字；未来需独立输入／输出／报价／结算合同，不作为整本成册依赖。AI初期每个计费子任务1张图，imageCount=1，不承诺人脸完全一致或seed逐像素复现。
- 初始原创／明确授权预设至少山水水墨、人像淡彩、花鸟写意3个；非商业、许可不明、过期、依赖未验证均不可上架；会员去品牌水印不移除AI来源标识。
- provider默认连接超时5000ms、单次请求60000ms；异步总时长不等于HTTP超时。并发／RPM取平台、供应商、工作区最严；dailyBudgetFen=0停止新付费任务。
- 预算按稳定accountBillingId、环境、Asia/Shanghai预算日预占＋已发生成本；同采购账户多个连接共享账户上限并叠加各自上限。80%告警，100%停新任务，跨日保留旧日未终局预占。
- 报价默认5分钟有效，未接受不预占；冻结configReleaseId、route/model/preset/costRule版本、inputHash、引用授权及policy。成功且审核通过结算一次，明确失败释放一次；状态未知先查询，建议30分钟终局，迟到不补扣／发布。
- 参考图只传用户选中且授权的图，默认剥离GPS／原文件名，不训练／公开复用；结果服务端受控拉取，quarantine→审核／显隐标识→ready；不把供应商临时URL当永久asset引用。

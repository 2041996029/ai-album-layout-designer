## 如何评审

先确认 C1 的交付边界和验收案例，再选择执行方式。建议本会话 AI 逐项执行：C1 的文档、字体、画布、预检接口联系紧密，顺序实施可减少上下文交接；完成后安排一次独立复核。也可选择每项任务分别由 AI 实施与复核，代价是更多独立上下文与协调。

用户提供的平台、商业模式和导出范围保持原确认结果。“全程 AI 开发”表示研发执行方式，并不等于已经具备微信主体资质、商户号、AI 供应商账号或部署凭据；这些在实际接入前按清单集中确认，不在每项本地开发任务前重复询问。

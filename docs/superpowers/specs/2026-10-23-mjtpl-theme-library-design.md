# MJTPL 导入与整套主题模板库

> 2026-10-23 范围确认：用户最新回复“1可以”，本次只实施 MJTPL 本地导入及其编辑、排版、导出链路。原创 96 个版式暂缓，本文相关内容为后续设想，不属于本次验收。

## 用户目标

用户已确认两者都做：导入上传的魔镜设计 `.mjtpl`，并参考其成册效果设计原创模板。
目标是同一主题下拥有多张可选择、组合的跨页，包含照片槽、标题、装饰与版式节奏。
现有 36 个基础固定版式保留，不能把仅更换底色的相同构图当作完整主题套装。

## 已验证的文件事实

MJTPL 样本是 ZIP，入口为 `manifest.json`，`format=MJTPL`、`formatVersion=1`、`schemaVersion=3`。
每页引用 `pages/.../scene.json`，并携带 PNG 预览；素材以 SHA-256 命名，部分包含 TTF。

## 架构与存储

新增纯转换包 `packages/template-import`，复用 fflate、现有资源端口与文档命令。
输入不直接写文档；先解析为 ImportedTheme，再生成可预览的转换报告，确认应用后提交一次原子编辑。
ImportedTheme 包含主题标识、源包哈希、页序、源页标识、尺寸、预览、照片槽、独立装饰层、字体及兼容性条目。
源素材和预览写入浏览器 IndexedDB 私有库，不提交 Git、不打包到公共站点。
导入库支持删除；删除前检查项目依赖，已有项目资源保留；备份包含实际引用资源和转换元数据。
不执行包内脚本，不访问包内 URL，包内文字仅作为模板数据处理。

## 格式映射

- `cm` 和 `ppi`：页面几何统一转换为 px96；61×30.5cm 样本对应跨页，文档单页为半宽。
- normalized transform：按跨页宽高还原，保留位置、尺寸、旋转、可见性、锁定与图层顺序。
- ARGB `#AARRGGBB`：显式转换为渲染颜色和透明度，不能误当 RGBA。
- `photo`：保留独立照片槽，区分待选片槽与演示照片。用户照片完整性统计仅包括实际选片。
- `material`：导入为独立装饰图片层，保持 alpha；照片统计排除装饰。
- 裁剪：将 `cropTransform` 转成现有裁剪表示，不能准确表达时出具兼容性条目，不静默重置。
- 蒙版：扩展文档、编辑器、公共渲染和导出为一致的 alpha 蒙版支持；替换照片不丢失槽位蒙版。
- 文字：有可用嵌入字体时保留可编辑文字；字体缺失、字形或排版不支持时，使用包内对应栅格层保留外观，清楚标记“外观保留”。
  用户可主动切换为本地字体并编辑，切换前预览差异；不把栅格文字宣称为可编辑文字。
- 不支持的混合、复杂变换和未知节点：记录页号与节点；可预览源页，但阻止将失真的转换页当作成功应用。

## 模板选择与应用

模板库显示主题封面、分类、页数和兼容性状态。打开主题后显示有序跨页网格与大图预览。
支持选择单个跨页应用，或选择一组跨页组织整本相册。
已导入的主题可在本地继续使用；与内置原创主题分区，保留来源。
应用前明确待替换照片槽数量、用户已分配照片、未分配照片、字体/蒙版兼容问题。
单次应用可一次撤销；重复应用不复用图层 ID，不丢弃原片。

## 整本排版

主题内按照片数量和横竖比例选择合适的不同跨页；优先保持主题页序和叙事节奏。
不能因为照片数量不匹配就静默换成通用网格。无法容纳时提示调整页数、版式选择或选片。
保留 C2 已有锁定、必选、禁止漏片/重复、过期候选阻止和导出完整性检查。
演示图、装饰和文字栅格不计入用户照片分配。

## 文件边界

逐项验证 ZIP 条目、扩展大小、条目数、解压总量和内容哈希；处理重复路径、非法路径、损坏 JSON 与截断文件。
采用受限解压，不能先无界解压再检查；取消操作释放解码图片和 Object URL。
在支持的资源上限内允许大于 32 MiB 的用户文件；超过上限时给出明确错误而非无响应。
照片导入沿用现有图像约束；模板装饰和字体使用独立的资源校验规则。
导入失败不留下半个可选主题，不改变当前作品。

## 验证与验收

- 合成最小文件测试：字段映射、色值、单位、裁剪、蒙版、字体回退、路径/大小边界、内容去重。
- 六个真实样本的页数、槽数、素材校验；每套至少代表页比较源预览与转换渲染。
- 浏览器：导入→主题预览→替换照片→单页应用→撤销→刷新恢复→备份恢复。
- 整本：不漏片/重复、装饰不计片、保持锁定、旧方案不能覆盖新编辑。
- 导出 PNG/JPEG/PDF 的蒙版、字体、裁剪与编辑器一致；至少一份真实导出与源预览比对。
- 原有 C1/C2 测试保持通过；未经读取的五种包列为未验证，不能凭扩展名声称兼容。

## 发布边界

发布代码与原创主题。上传的包、字体、装饰和样片只在用户本地导入，不随站点公开发布。
导入为离线格式转换，不依赖外部 AI；后续 AI 照片理解不属于本次交付。

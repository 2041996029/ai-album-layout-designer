# 后台重设计与服务器测试交付

目标：把 C4 单张长表单改成摄影相册产品的运营控制台，并提供可交给本地 Codex 的完整源码与服务器测试部署包。目标目录 `/www/wwwroot/HuaNian_SheJi`。

采用现有 React/TypeScript 与 API，不引入新 UI 框架。默认浅色内容区、深色侧栏、绿色主操作；六个独立模块：总览、订单、退款、兑换、权益调整、对账。表格与表单分区，提供中文状态、金额与日期、已加载记录搜索、分页和明确空态；来源选择后直接进入调整模块。原有权限、用途绑定验证码、幂等及退款源绑定保持不变。无连接时展示连接状态，统计用破折号，不能把样例或第一页汇总冒充经营总量。手机宽度可导航和操作，长 ID 不撑破页面。

比较：仅换 CSS 无法解决功能堆叠；迁入完整新管理框架会增加依赖和重做交互。本轮选现有技术上的控制台重组。视觉方向是开发者暂定值，用户偏好可调整。

交付包含全部已跟踪源码/锁文件/字体模板/SQL/部署文件；排除凭据、上传附件、运行数据、node_modules 和旧文档二进制交付包。Docker Compose 测试栈：同源 Nginx 前端与后台、Node24 API、Postgres17、Redis7，真实持久卷和首次初始化 SQL；仅在新卷初始化，重启不得删库。测试环境明确 C3_ENV=dev，绑定本机端口供宝塔反代；它不是生产就绪承诺。密钥初始化脚本只生成缺失文件，不覆盖现有秘密。提供 .env.example、宝塔反代与本地 Codex 搭建/验收/备份/升级指导以及源码 ZIP 和 SHA256。

不添加测试登录后门，不虚构商户/短信/AI适配器；受控测试可以启动本地 API/编辑器和查看后台，真实登录及云业务需既有部署适配器。缺失功能在说明与界面如实呈现。当前用户负责远程部署，本轮不连接或改动远程服务器。

# 模板与滤镜交互打磨

按用户明确要求执行：复杂选择交给系统。主题外层只显示一个主题卡，1/2/3/4 图版式位于主题内部；点击卡片按已选画布照片（支持组合）优先、否则已导入照片顺序，选择容量最接近且足够填充的版式，自动填片并应用当前跨页。可展开调整照片，不重复照片，不隐藏多余照片，提供一步撤销。保留整套应用和旧基础版式入口。

滤镜默认自动范围：选中照片时只处理选中照片；未选中照片时处理整本的可编辑用户照片。明确显示范围，支持主动切换整本；锁定照片、装饰和文字不受影响。一次操作一次撤销。

沿用现有 React、图层命令、资源验证与导入事务，不新增外部服务。选择逐框绑定作为主流程不符合用户要求；直接整本替换会扩大点击的影响，因此主题点击只改变当前跨页，整本仍有明确入口。

# v0.4 配置中心与素材目录：规格增补

日期：2026-10-21（北京时间）。状态：供评审的功能规格；不是已实现后台，也不是已联通云服务。继承 [v0.3 基线](../design-v0.3/README.md)的产品范围，本轮修补云存储、文件夹、AI 及其他运行配置的缺口。

## 本轮核对结论

此前文件已经覆盖编辑器、登录、会员、导出与 AI 的主业务方向，但**配置功能尚不完整**。v0.1 只列出对象存储、AI endpoint/key 和环境配置，未定义配置字段、用户文件夹、发布回滚和故障行为；C1 计划仅交付本地编辑与导出，不能替代云服务与运营后台。

本轮补齐的是配置中心的设计合同。正式 OpenAPI、迁移、各供应商适配器、后台代码、真实连接测试及全部模块实施计划仍在后续开发中生成，不能据此宣称产品已具备完整上线条件。

## 推荐边界

首期推荐“平台统一接入＋工作区个性设置”：平台管理员配置存储与 AI 服务，用户配置素材文件夹、相册默认参数和通知偏好。两种自定义目录分别设计：后台存储根前缀，以及用户可见的逻辑素材文件夹；后者不直接暴露云对象 key。

“自定义文件夹”正在向用户确认具体所指。在答复前，两类均列为推荐规格，不能记为用户已经确认。工作区自带存储／自带 AI Key（BYOS／BYOK）作为候选扩展，首期默认关闭；若用户要求首期开放，需要另补授权、费用、密钥托管与故障责任合同。

## 与既有计划的关系

- C1 继续本地编辑与确定性导出；预留稳定 assetId，不把云路径写进文档层。
- C2 使用模板／规则版本与排版参数，不把普通规则排版计入生图点数。
- C3 增加云存储 profile、上传／目录 API、工作区权限和配置读取。
- C4 增加配置发布、任务快照、资源 pin、会员 SKU／配额、账单与告警。
- C5 增加 AI provider/model/route/preset、报价／审核／标识及运营配置。

本增补若评审通过，C3–C5 开工前必须将其拆入对应详细计划；当前 C1 计划不等同于这些模块的实施计划。

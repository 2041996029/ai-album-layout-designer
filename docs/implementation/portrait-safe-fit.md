# 自动填图避免裁切主体

2026-10-24：修复近景竖幅人像被横向模板居中裁成半张脸的问题。

原因：原生模板默认 Cover；导入主题替换照片也强制 Cover；整本排版在没有主体位置时仍做中心裁剪，有主体裁切风险时仅警告。

改动：
- 模板替换与导入主题默认完整显示，保留画框位置和模板装饰。
- 整本排版缺少主体位置时使用完整图；有位置依据时检查同一照片的全部主体及边缘余量，不安全即完整显示。
- 普通照片插入按原比例限定尺寸；更换照片不继承旧照片的 Cover 裁切。
- 工具栏「修复照片裁切」一次恢复整本相册的照片完整显示；保留框位、滤镜、装饰及锁定子树，支持一次撤销。
- 用户仍可手动选择铺满或主动裁剪；不自动改写已保存的旧作品。

这里没有新增人脸识别或 AI 模型。完整显示可能保留空白；导入模板已有的蒙版仍按原模板保留。

验证：先复现模板填图与整本排版的错误默认裁切（两项失败回归），修复后通过。`npm test` 为 224 passed / 55 skipped（未配置本地 PostgreSQL）；裁切修复相关浏览器 16 项、导入主题与响应式 8 项通过；TypeScript 和生产构建通过。数据库用例由 C3 CI 的 PostgreSQL 服务运行。

## 使用

「模板与滤镜」→ 选择模板分类 → 预览 → 为照片框选片 → 应用。
预览使用前四张可用照片展示构图，应用绑定由用户单独指定；无照片时显示几何示意。
背景、图层及模板引用作为一次编辑提交，可以整次撤销。图文保持可编辑。
「智能排版」同样可选全部风格；根据实际分配的 2–4 张照片匹配同风格固定版式，备选提供填满与完整显示的照片适配。
照片数超出固定版式范围、页面比例不同或存在锁定内容时沿用已有网格回退与提示。
原有基础模板仍保留备选网格方案，照片完整性检查不变。

模板定义在 `packages/document/templates/styles-v1.json`，由
`npx tsx scripts/build-style-templates.ts` 重建，使用 canonical JSON SHA-256 注册。
字体复用项目本地 Noto Sans SC / Noto Serif SC。模板没有外部图片依赖，不调用 AI，
也不会自动给原照片施加滤镜；“黑白写真”等名称表示版式风格。

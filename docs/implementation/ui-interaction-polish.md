# 模板、滤镜与导出交互优化

## 发现与改动

模板库增加风格搜索、空结果提示和清空筛选；当前跨页的真实模板来源决定卡片的使用标记，避免把仅预览或应用失败的模板标为已用。套装提供明确返回入口，套用期间锁定重复提交。浏览模板、套装详情、滤镜以及照片栏之间切换时保留面板状态和筛选。

滤镜增加搜索、实片缩略图、当前滤镜标记、混合状态和明确的作用照片数。缩略图使用现有像素内核及默认强度，保持完整照片；只读取一张预览并缓存同一来源，丢弃迟到结果。强度跟随真实文档与撤销状态，没有滤镜时禁用滑块。分类与原图合为一行，小高度窗口收紧重复说明，保留可见预览；滚动时强度控件和分类导航保持可用。

导出报告按代码与预警等级汇总，同类问题不重复铺满窗口。每组可展开所有页面与原始描述，支持按类、逐条或整批确认；半选状态和原始 issue ID 保留，底层导出校验不变，处理期间不能修改确认。输出尺寸与内存说明折叠。标题和导出操作固定在滚动窗口边缘，确认后的状态及时更新，取消导出仍明确显示取消，多个文件的单独下载收进详情。

额外修复默认全选照片时取消一张会误清空其他选片的问题，并增加素材选择的可见边框反馈。

## 验证

- 单元测试 234 passed / 55 skipped；本地未启动 PostgreSQL，数据库用例由 C3 CI 运行。
- 完整浏览器回归 98 项通过，1 个旧导出用例仍直接操作已折叠的预警；改为分组确认并展开单文件下载后，真实 PNG 和 ZIP 下载复测通过。
- 收紧滤镜控件及取消反馈后，模板与滤镜专项 15 项通过；最终 UI 与真实导出专项 7 项通过，包含新增取消导出用例。
- TypeScript、生产构建、差异检查通过。实际查看滤镜和十跨页导出窗口截图，确认预警已汇总、操作保持可见，小高度窗口首屏能看到滤镜预览。

# 模板成册、选片、裁剪与导出交互修复

2026-10-24

## 用户行为

- 智能排版按命名主题选择。图数变体合并在主题内部，系统按照片数量自动选择，支持原创主题与本地导入 MJTPL。
- 点击原创套装会实际生成并应用整本布局，显示真实照片数、跨页数；能一次撤销。点击套装默认应用全部八个版式；主题面板的整本按钮严格使用勾选的跨页，缺页自动新增，旧的未锁定内页整体替换。照片不足时保留页数、照片位留白；照片超过容量时自动追加勾选的版式。剩余照片通过容量规划分配，图片不漏用、不重复，最多五十跨页。无法匹配时保持原作品并说明原因。
- 照片库、排版选片、跨页与云素材、导出页面和预警确认提供全选及清空；排版照片还可反选。明确清空选片与默认使用全部照片区分。
- 双击照片或点「裁剪照片」进入固定画框取景。拖动的是照片，画框坐标与尺寸不变；缩放取景可调，应用和撤销各为一个操作。
- 导出文字问题显示具体跨页和文字内容；「自动适配溢出文字并重新检查」使用真实字体测量、缩小字号及字距，保留文字和画框。不能在最低可读尺寸内放入的内容仍阻止导出并要求扩大文字框。锁定内容保持锁定。

## 问题根因

整套主题入口此前只切换面板；整本手动流程要求总照片槽数恰好相等。现增加自动容量规划，并允许重复使用同套版式容纳更多照片，仍保证照片唯一。显式整本替换可替换旧的未锁定页面，原有锁定约束继续验证。

原裁剪窗口默认完整归一化区域，无移动余量；现以匹配画框比例的取景开始，指针位移转换为反向的照片取景移动。

`TEXT_OVERFLOW` 与预计工作集内存无关：它检查文字行框及实际字形墨迹是否越过文字框。本次调整原生模板文字框的最小高度、避免能容纳的轻微字形悬垂误报，并保留对真实溢出的检查。`464 MiB` 等工作集数字表示预计峰值内存，不是下载文件大小。

## 验证

- 本地 `npm test`：231 passed / 55 skipped；数据库未在本地启动，相关用例由 C3 CI 的 PostgreSQL 服务运行。
- 完整浏览器回归 90 passed；容量余数与加载互斥修复后模板专项 9 passed；额外 MJTPL 智能排版及蒙版实际字节落库 1 passed。
- TypeScript 与生产构建通过。
- 自动排版仍是本地规则和模板规划；此改动没有接入新的 AI 模型。

## 全选跨页补充修复

此前全选只更新复选框，整本按钮仍忽略勾选并按照片数重新规划，导致勾选八页仍只有两页。现在整本按钮直接使用勾选顺序，手动整本入口同样支持新增和替换；单个版式与「替换当前跨页」保留单页用途。稀疏成册先为各页分配一张照片，再填余下照片位，不引入样片或重复用户照片；空照片位的图像层从实际组合及对应来源证明中移除，保留其余装饰和文字。锁定内容不兼容时整次操作失败，不部分替换。完整内页替换是一个命令，可一次撤销。

补充验证：本地单元测试 234 passed / 55 skipped，TypeScript 与生产构建通过；模板成册、裁剪、导出相关 20 个浏览器用例通过（专项回归 19 个通过后，修正追加页数的测试预期，剩余 1 个复测通过）。新增用例检查 IndexedDB 保存后的实际页数、八个来源版式、照片唯一性及整本撤销；领域测试覆盖稀疏照片、删除多余旧页和锁定旧页拒绝替换。

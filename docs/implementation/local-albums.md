# 本地相册切换与命名

顶部名称原为固定文案，浏览器内虽保存多个项目却没有本地切换入口。现点击顶部相册名称打开「我的相册」，可重命名当前相册、新建空白相册或打开已有相册。

名称作为 IndexedDB 项目元数据保存，普通保存保留名称，不修改文档内容与版本 CAS。切换或新建先等待编辑器完成保存，保存失败保留当前编辑器并提示；照片/模板处理期间不切换。新相册沿用尺寸、印刷参数和字体，从空白封面与单个空白跨页开始。当前项目 ID 保存在 album-active，刷新恢复当前相册。此入口管理浏览器本地相册，不会重命名远程云项目。

验证：本地 234 项单元测试通过，55 项数据库用例因本地未启动 PostgreSQL 跳过；生产构建和 TypeScript 通过。云工作区与本地相册专项 12 项浏览器用例通过；补充保存失败阻止切换后，本地相册 2 项专项再次通过，覆盖改名、保存后名称保留、新建、切换、刷新及失败保留编辑。

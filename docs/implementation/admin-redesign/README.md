## 实现取舍与代价

1. 视觉默认采用浅色内容区与深绿导航，沿用已有 React 技术栈；如需其他风格，返工集中于后台视图与 CSS。
2. 总览统计明确限定“已加载记录”，不增加伪造的全站收入/增长率；全站聚合报表需要后续服务端接口。
3. 测试部署使用已有 dev 本地存储模式，不增加登录后门或假渠道；真实身份和云业务仍需可信适配器。
4. 源码包保留程序样例与验证资源，排除旧文档二进制交付包、凭据、附件和运行备份；如需历史文档全量包，使用仓库本身的归档。
5. 严格宿主文件权限通过镜像内明确的文件所有权/可读权限解决；数据库迁移固化进镜像，健康检查验证最终表存在，不把失败的半初始化库视为就绪。

仍保留的测试环境限制：API 运行身份可写镜像内应用源码。正式部署需进一步使用 root 所有/只读代码与独立可写对象卷；本包未将它标记为生产加固完成。

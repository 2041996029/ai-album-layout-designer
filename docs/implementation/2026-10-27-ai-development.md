# OpenAI 兼容生图与腾讯 COS 开发记录

用户选定 OpenAI 兼容接口与腾讯云存储。本分支是 C5 开发版本，尚未完成全部 C5/C6，不作为生产发布。

## 本次代码

- 腾讯 COS 官方 SDK、私有对象、哈希校验、配置版本路由。
- 版本化供应商契约、OpenAI Images 文生图与可选参考图编辑、SQL 提交回执。供应商受理状态未知时只确认原请求。
- 授权与策略校验、报价、点数/采购预算/存储配额原子预占、上海时区预算日。
- 持久任务、取消与 fencing、结果校验与审核、带标识的标准图片与预览、来源记录和导出检查。
- 对象上传前持久化暂存日志，上传、发布与清理使用相同记录锁；提交确认丢失不能误删已发布文件。
- Web AI 创作入口、报价确认、失败重试幂等键、结果轮询、参考图授权；共享文档提供不覆盖原图层的插入命令。
- 006 增量数据库升级与服务器私有配置说明。

## 验证方式

供应商测试使用明确的 replay/请求注入，COS 测试使用 SDK 端口替身；业务任务与账本使用本机隔离 PostgreSQL/Redis，浏览器使用实际 Chromium。未进行真实付费调用、真实 COS 写入或服务器部署，不把这些离线结果标为 live。

重点覆盖十个并发报价接受共享一个预算、报价不扣点、重复接受、上海午夜、受理后超时恢复只提交一次、审核拒绝/不可用、取消与成功竞态、结果域名拒绝、提交确认丢失仍保留已发布对象、原图下载哈希与带标识资源一致、模型与预设策略不匹配拒绝发布。浏览器覆盖修改描述使旧报价失效、固定幂等键重试、终态作品预览与未开通状态。

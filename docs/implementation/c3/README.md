# C3 账号、私有素材与跨端

此阶段提供可运行的 NestJS/Fastify API、PostgreSQL 身份与工作区权限、私有文件系统开发适配器、真实图片上传归一化、逻辑目录与回收恢复、云版本 CAS、网页云工作区和原生微信小程序源码。产品文档继续使用 C1 模型，C2 排版与本地编辑保持可用。

## 当前能力与接入边界

| 项目 | 当前行为 |
|---|---|
| 身份 | 经过服务端验证的身份端口；OpenID 按 provider/AppID 隔离，可信同开放平台 UnionID 才关联；会话轮换、重放撤销、扫码浏览器绑定、CSRF 与重新验证证明已实现 |
| 真实微信、短信 | 尚未配置实际身份交换/二维码供应商适配器与资质，默认 `unconfigured`；没有假扫码成功或通用测试账号 |
| 素材 | 开发适配器保存实际私有字节，验证 JPEG/PNG、EXIF 归一化、SHA、尺寸、配额和原子完成；不公开素材目录 |
| OSS/COS/S3 | 本阶段未实现并激活实际厂商适配器；`ObjectStore` 接入端口明确，不能把本地文件系统称为已上云 |
| 字体 | 仅显式开发引导可安装项目自带 OFL 字体的真实文件与许可；用户上传的私有字体不自动声明为平台已授权字体 |
| 工作区/目录 | 逐次数据库授权，个人与影楼角色/席位预留；目录、回收、恢复、CAS、引用阻止、分页与用量；不提供邀请 UI |
| 云版本 | PostgreSQL 原子 CAS，至少 20 份历史（当前保留全部），资源版本/归属/哈希核验；跨设备冲突保留本地草稿 |
| 小程序 | 原生源码、选片上传重试、轻编辑/裁剪、候选与任务接口、离线恢复；高级字段保留，仅简化预览，真实微信开发者工具和设备未联调 |
| 分享/通知 | 冻结预览、哈希分享凭据、撤销/到期、授权与去重；真实外发未配置，C4 导出/任务未就绪时不制造预览或消息 |
| 注销/隐私导出 | 证明、封禁新授权、会话/分享撤销、阻塞和取消已实现；清理/导出调度端口未连接时返回未配置，不显示已完成 |
| C4 依赖 | 持久任务调度、商业权益、真实导出后台任务和云排版调度仍待 C4，不在 C3 假装已交付 |

公开测试站是静态 GitHub Pages，不能托管 PostgreSQL/API。网页仍默认本地编辑；云面板准确显示当前服务/登录状态。没有发布真实云后端、生产数据库或用户原片。

## 网页交互

从顶部「云工作区」查看登录和云项目。未接通后端时仍可本地编辑、备份与导出。已登录且服务实际配置后，可切换工作区、整理目录、上传照片、打开云项目和保存到云端。点击云素材会下载并核验原图后直接导入当前照片库；无需手动下载再上传。工作区默认尺寸仅用于新建云相册，已有作品不变；已有分享可查看有效期并撤销。

保存前先写本地恢复副本；409 不自动覆盖其他设备版本，迟到响应不改变当前工作区。打开云项目先核验和下载资源，再建立本地副本，失败不会覆盖现有作品。字体必须与本地已授权文件一致，缺失会明确拒绝。

## 本地开发

Node 24，临时 PostgreSQL 17。仅在新建、可丢弃的本地数据库运行迁移，脚本拒绝覆盖已有 schema。

```bash
npm ci
npm ci --prefix tools/api-codegen
npm run api:types:check

# 自行创建空的本地 album_dev 数据库，凭据由环境注入；不要提交真实值。
# C3_ENV=dev
# C3_DATABASE_URL=postgresql://...@127.0.0.1:5432/album_dev
# C3_AUTH_SECRET=<至少32字符随机值>
# C3_ALLOWED_ORIGIN=https://你的本地网页域名
# 可选开发文件适配器：C3_LOCAL_STORAGE_ROOT、C3_LOCAL_OBJECT_SECRET、
# C3_DEV_STORAGE_LIMIT_BYTES、C3_PUBLIC_API_ORIGIN
npm run api:migrate:dev
npm run api:dev
```

开发前端默认同源 `/v1`；生产构建仅在设置 `VITE_API_BASE_URL` 后启用云端请求，静态预览不会探测不存在的 API。部署可将变量设为 `/v1`，再把该路径反向代理到 API。跨域时使用构建变量 `VITE_API_BASE_URL` 和精确允许 Origin；Cookie 必须 Secure/HttpOnly，普通 HTTP 公网环境不属于有效部署。生产环境拒绝 local 存储配置，没有测试身份开关。

`C3_TEST_DATABASE_URL` 只接受 localhost/127.0.0.1 且库名含 test；测试每个套件自行创建/删除独立数据库。未设置该变量时 PostgreSQL 用例会明确跳过，不能据普通单元测试声称数据库验收通过。

```bash
C3_TEST_DATABASE_URL=postgresql://...@127.0.0.1:5432/c3_test npm test
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
npm run typecheck
npm run build
```

开发用量边界来自显式本地策略，不代表免费/付费商品价格或商业权益。分享下载直链签名有效期最多 300 秒；撤销后不再签发，旧直链可在剩余有效期内继续访问。分享初始 token 仅返回一次，幂等重放不存储/返回原始 token；若初始响应丢失，应撤销后重新创建。外部通知适配器必须兑现事件幂等键，否则无法承诺网络故障窗口的第三方严格一次发送。

## 合同修订

原 HTTP manifest 只有摘要，不能无损重建 C1 的原图/预览/字体子集和许可。增加了 `ProjectDocument.resources`、仅 web 可发送的 `ProjectPatch.resources`、`Asset.editorResource`，全部由服务端校验；没有新建第二种相册文档模型。补齐 DocumentCommand 小写 discriminator 映射和扫码轮询 nonce 参数。

新增运行时 SQL 位于 `apps/api/src/c3-runtime.sql`：扫码上下文、重新验证/注销恢复范围、不可变 revision 载荷与资源索引、字体集合、通知授权、分享冻结输出。资产元数据 CAS 与不可变 `content_version=1` 分开，目录操作不改变内容哈希。local provider 数据库约束仅允许 dev。

# 架构、模块依赖与供应商集成合同

## 1. 代码与部署职责

采用Node24 LTS、TypeScript、React／Vite／Fabric网页、原生mini TS/WXML、NestJS模块化API、PostgreSQL事实源、Redis／BullMQ调度、对象存储；导出与AI独立worker。C1精确候选版本在原计划；backend版本由技术验证锁定package-lock和镜像摘要，不把候选当已测试。首期不用微服务／Kubernetes增加运维要求。

预期代码路径：packages/document、assets、storage、render、export、layout、contracts；apps/web、admin、api、mini、export-worker、ai-worker。实际文件由各单元计划列明，计划执行前核对真实分支与依赖；不在本次文档包创建空服务冒充实现。

依赖序：C1→C2；C1文档端口→C3；C3＋C1渲染→C4；C3＋C4→C5；OPS跨单元持续记录证据，最终全链路准出。C4配置、队列、权益可独立验证，但支付需要渠道资质，AI真实调用需C5授权和预算。

## 2. 核心数据流

上传：成员权限／额度预占→短期上传签名→原始对象→格式／像素／方向验证→归一图／预览→ready。文档保存使用当前revision CAS，新增不可变revision。mini仅可修改允许文本、crop、页面顺序和候选选择，未知高级字段透传；非法patch拒绝。

导出：保存→预检token绑定文档／资源／选项hash→验证权益／警告确认→事务建立快照、job、pin、Outbox→worker取得递增fence→同包渲染／编码→临时对象→条件提交产物→下载鉴权。取消／重复投递／旧worker不能产生第二个合法结果。

生成：已发布预设→用途／参数验证→Quote→点数／平台预算同事务预占→Outbox→提交或查询→结果隔离解码→审核／标识→私有新素材→唯一结算。发布新模型不会更改已有报价／任务；状态未知只查原供应商，不盲重提。

配置：草稿→字段／依赖／秘密权限→绑定hash的测试→release原子指针切换；旧任务继续用冻结版本。回滚配置复验旧凭据，不改历史账本；紧急停用可阻断新请求并对已有任务明确终结／补偿。

## 3. 端口合同

| 端口 | 必要操作／返回 | 失败语义 |
|---|---|---|
| StorageAdapter | probe、signUpload、head、read、put、copy、delete、signDownload；每项含profileVersion／objectRef | 明确不存在／无权／限流／临时错误；禁止自动读缩略图代替原片 |
| IdentityAdapter | exchangeMiniCode、createWebQr／consumeScene、verifyBinding、refresh／revoke | 一次凭据单次消费；缺UnionID不合并；token不返回session_key |
| PaymentAdapter | createPayment、verifyRawEvent、queryPayment、refund、queryRefund | 验签和金额／商户／应用／商品一致后正规化事件；ACK按渠道合同，不固定先ACK |
| GenerationProvider | describe、validateParameters、estimateCost、submit、query、cancel（若支持）、fetchResult | accepted／rejected／unknown区分；不能将超时当明确失败后重新付费提交 |
| ModerationAdapter | checkInput、checkOutput、labelRequirements、appealStatus | 审核缺失不发布；有来源和策略版本，timeout不能当审核通过 |
| NotificationAdapter | canSend、send、queryReceipt、unsubscribe | 用户授权／订阅次数／限流；通知失败不回滚已成功付款／导出 |

provider的机器可校验元数据和输入／结果见[provider schema](contracts/schemas/provider.schema.json)。外部签名算法、状态映射、错误重试、endpoint、限制与计费必须由具体adapter契约报告确认；统一HTTP格式不意味着业务兼容。

## 4. 所有第三方的准入报告

每个adapter交付：供应商／文档日期、SDK或HTTP版本及许可、主体与服务区域、数据用途／训练／保留、认证和轮换、请求与返回映射、单次费用和成本口径、幂等与查询／取消能力、回调签名／重放、限流、故障矩阵、沙箱／小额真实验收记录、退出与数据删除方式。

候选OSS／COS／S3兼容分别测试；没有实现的adapter不出现在可启用列表。AI聊天兼容不代表参考图生成兼容；风格名称不能代替模型commercial许可。支付渠道未开通或mini平台能力不足时返回capability不可用，不设计绕过购买限制的引导。

## 5. 渲染与字体合同

自有JSON模型权威，Fabric仅映射。EXIF方向归一化一次，filter在归一图源坐标先应用再crop；CPU kernel、seed、recipeVersion固定。固定Chromium、字体bytes／许可／hash、locale／DPR与渲染build进入manifest。CJK文字分段／禁则／度量预览与导出共用，缺字／超框阻断；不回退系统字体。

同环境重复快照比较解码像素hash，不要求ZIP时间戳或不同系统JPEG编码字节相同。PNG pHYs／JPEG JFIF密度与实际像素分别验证；普通PDF MediaBox／TrimBox／BleedBox和页序独立校验。服务端进程出站仅允许自有manifest和已批准供应商结果域；不接受用户URL／脚本／file路径。

## 6. 数据和运行合同

[OpenAPI](contracts/openapi.yaml)是传输合同；[schema目录](contracts/schemas)定义业务文档／布局／配置／导出／provider输入；[数据库目录](database)定义持久化；[状态机](03-状态机与一致性.md)定义事务边界。结构校验之外还必须执行语义验证和工作区权限。

worker部署预算必须经过实际容量测试；BullMQ锁不代替数据库fence；Redis重建不按缓存余额恢复财务。可观测日志关联requestId/jobId/orderId，不泄露token／签名URL／提示词／原片／个人资料。数据库UTC，预算日Asia/Shanghai。

# 产品与模块统一基线 v1.0

日期2026-10-21，北京时间。此稿统一v0.1–v0.4的评审设计，交付范围为全模块研发文档与设计合同。实际代码、账号资质、付费服务和生产部署不包含在文档完成声明中。

## 1. 用户、端与成功条件

摄影师／影楼要精细排版、复用客户素材和稳定交付；个人用户要手机上传后快速成册。网页负责完整图层，小程序负责上传、模板、规则排版、文本替换／裁剪、预览和任务找回。后续App复用内部用户、文档、权益及任务API；首期不交付App安装包。

普通照片成册保持照片内容，AI艺术创作明确可能改变人物和场景。用户能核对照片去向，改标题不用重新生图；预检失败给出可修复原因，排队时继续编辑不改变导出快照。大陆微信生态与人民币优先，微信／支付按实际主体与当期能力上线。

## 3. 容量与默认值

文档schemaVersion1、px96、sRGB；pageSize为单页，spread宽为2倍，封面独立。1–50内页跨页、2–100内页、500照片／项目、100递归图层／面、组深度≤5；JPEG／PNG≤25_000_000字节、≤80_000_000源像素。容量为设计上限，实测不过则明确收紧配置并提示，不写成已有性能保证。

导出DPI72／150／300、≤50MP／面；先预检再冻结；600×300mm、300DPI裁切区7087×3543像素，四边3mm出血为7157×3614。普通PDF为sRGB栅格页，不承诺PDF/X、CMYK、拼版或印厂签收。缺字／文字超框阻断；有效PPI100–199警告、<100强警告，可在数字导出明确确认继续。

保存空闲2秒／持续10秒触发，至少100步撤销、20恢复版本；历史文件不会因新模板／滤镜发布自动升级。浏览器C1预算768MiB、headless2GiB、图片缓存128MiB，保守估算超限拒绝；运行服务有单独实测进程预算，不能仅按CPU核数开并发。

## 4. 配置与目录的完整边界

平台后台统一接入存储与AI；用户自定义素材逻辑文件夹；后台可改根前缀，但仅影响新写入。首期覆盖20配置域，schema有21种typed value（含相册默认值albumDefaults）。配置草稿、测试、发布、回滚、秘密版本、权限和审计均纳入；数据库／Redis／秘密服务引导地址放部署层。

目录1–80个Unicode码点、NFC和大小写折叠去重、最多10级、同工作区；移动防循环／CAS，使用中素材阻断整批删除，回收／恢复不覆盖同名目录。对象key用随机ID／hash，不含客户姓名或目录名。BYOS／BYOK、目录独立共享ACL、智能标签相册为后续范围。

## 5. 身份、商业与内容

内部用户随机ID；不按昵称／同手机号自动合并。工作区owner购买／兑换／申请退款；角色不等于设备数。影楼初期单使用者，数据保留席位／角色，邀请UI以后开放。管理员业务权限不自动获得客户照片访问权。

免费／个人／影楼会员与AI点数包按SKU版本配置，价格与额度由经营者确认。首期不自动续费；期限用天数。AI以子任务单图计价，quote建议5分钟；接受后原子预占点数和平台成本，成功审核通过结算，明确失败释放；未知状态终局建议30分钟，不自动跨供应商双提交。

会员去品牌水印不去AI来源标识；用户原片不默认用于训练或公共素材库。模板、字体、滤镜、生成风格有不可变版本和许可记录；非商业Zine Skill不安装／不调用为商业能力，参考调研保持来源证据。

可选外部标题／章节建议模型在首期仅预留关闭；未具备独立文本输入／输出与计费合同前不启用，普通标题编辑和规则排版始终不依赖它。

## 6. 范围外与技术假设

首期不含多人实时协同、PSD／RAW／HEIC、任意上传SVG、专业印刷、自动续费、设备离线许可证、素材公开交易市场、App安装包、BYOS／BYOK。它们不是未完成首期模块，若纳入需显式变更范围和合同。

自定义目录两类、具体供应商／价格、真实微信／支付能力、部署预算为明确决策项，见[决策记录](07-决策与接入清单.md)。本轮不为这些决策编造真实值；所有依赖缺失都有disabled/unconfigured行为和验收用例。

## 7. 权威顺序

本目录统一基线与明确的schema／OpenAPI约定优先于历史示例；业务不变量优先于UI示意。数据库SQL负责已声明约束，跨表账本、照片完整性、权限与供应商状态由事务／服务验证补足。对应变更必须同时改需求追踪、接口、schema、SQL、页面、计划与用例；禁止只改一个版本的字段名。

历史材料在同包docs相邻目录保留；旧文档中的“团队未提供”等历史状态由本轮“全程AI开发”取代，不能把旧估算区间当交期。

# 决策、假设与真实接入清单

本表完整记录尚未由经营者确定的输入，不将外部账号／价格伪造为技术缺失。所有模块先有默认禁用、契约模拟和可验收设计；真实能力启用前逐项关闭阻断。

| ID | 项目 | 当前基线／默认 | 何时确认／影响 |
|---|---|---|---|
| DEC-01 | 自定义目录 | 暂定后台根前缀＋用户素材逻辑目录，两类均设计 | C3接口评审前；可减范围，不阻断文档编制 |
| DEC-02 | 云存储 | OSS／COS／S3分别适配，平台统一私有存储 | C3真实联调；选择供应商、区域、桶、域名、凭据权限、预算 |
| DEC-03 | AI服务 | 平台统一模型配置，无用户BYOK；三种原创候选风格 | C5真实联调；模型／商业条款／数据用途／成本／标识审核 |
| DEC-04 | 商品价格与额度 | SKU版本化，无真实售价；模拟环境用明显TEST商品 | C4上线前；价格／有效期／赠送／退款和毛利确认 |
| DEC-05 | 微信能力 | web／mini分开AppID，UnionID仅可信范围关联 | C3联调；主体、类目、回调域、平台权限 |
| DEC-06 | 支付渠道 | 网页与mini虚拟权益各自adapter，能力不足不开放购买 | C4联调；商户与应用、凭据、证书、公钥、准入与iOS等限制 |
| DEC-07 | 部署成本与可用性 | 独立API／worker、托管PG／Redis、私有对象；不用K8s作为首期前提 | 预发；云区域、实例、备份、告警接收、域名／证书、成本上限 |
| DEC-08 | 保留与隐私 | 30天回收、7天导出为建议值，原片不默认训练 | 发布前；经营者确认公开政策与适用规则，数据库tombstone同步 |
| DEC-09 | AI开发执行 | 全程AI已确认；推荐本会话顺序执行，单元后独立复核 | 编码启动时确认本包基线和执行方式；不重新询问团队人数 |
| DEC-10 | 模板与视觉 | C1五类原创种子模板、33配方数值合同；视觉需真实评审 | C1验收；字体许可、授权照片、中文、肤色／色卡确认 |

接入秘密只通过环境秘密配置或密钥服务注入；聊天／文档／Git中不收集明文key。无需用户逐字段设计技术参数，开发者依据schema、权限和测试记录落实。跨模块变更填change-log，标明影响的需求、API、数据库、计划、原型和验收，不能只更新一页。

产品代码实施按已启用Superpowers架构流程评审本包和单元计划后开始；用户本轮明确授权完整文档编制，因此不因等待增量文档批准而留下文档空白。真实付费调用／发布仅在其具体实现和费用可审查时按授权范围处理。

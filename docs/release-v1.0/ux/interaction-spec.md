## 1. 页面登记与角色的阅读规则

[pages.csv](pages.csv) 是唯一页面 ID 登记表：WEB-01～22、MINI-01～09、ADMIN-01～28、COMMON-01～06，共 65 个页面／复合视图。编号稳定，后续追加不能复用已退役编号。route 是产品导航设计，不是承诺存在的服务地址；mini:// 是小程序路由记法。动态参数只能引用当前授权资源，前端传入工作区不等于有权访问。

每页明确主要动作与 loading、empty、error、forbidden、offline、conflict 六类状态。非可编辑页的 conflict 指服务器状态或资源授权变化，不能为满足表格而提供“强制覆盖”。所有错误就地保留合法输入；敏感验证码、支付凭据、完整兑换码和秘密不持久化。跨工作区切换清空上一区的敏感表格及未提交财务选择；未保存文档先走保存／本地副本流程。

[permissions.csv](permissions.csv) 是 54 个动作 × 10 个角色的矩阵。DENY 是默认；ALLOW 仍需登录、作用域、资源状态、平台能力、权益和服务端校验；CONDITIONAL 用于分享令牌；SCOPED 表示额外命名空间／字段／专项权限约束，绝非全后台管理员。guest 是访客；owner/workspace_admin/designer/viewer 属于工作区；support/content/finance/ops/auditor 是平台角色。一个人可以兼任，但每次操作须明确作用域，不把平台角色叠加成读取所有客户照片的能力。个人区只有本人；影楼首期单使用者，邀请与多席位管理仅预留，界面不得出现可用的邀请按钮。

界面矩阵的workspace_admin对应API／SQL的工作区role=admin，是同一角色的显示别名；平台ops等角色独立，接口不能接收显示别名来提升权限。

采购、订单详情、退款和兑换首期仅 owner；workspace_admin 管理区默认值与作品素材，不自动有财务权限。designer 可编辑和回收无引用素材；任一相册／活动任务引用都会整批阻断回收。viewer 只读获授权作品、历史、任务与产物，不提交导出、生图、取消、分享或恢复。页面登记的角色白名单与动作矩阵取交集；同一矩阵行涉及多页时，不扩大任一页的角色范围。未列出的操作一律禁止。平台人员仅看各域摘要；为审核必须临时查看隔离内容时，另需 purpose 权限、范围、期限和审计，不能添加通用客户原片列表。

## 2. 全端反馈、保存与版本冲突

保存指示固定使用“保存中／已保存〔时间〕／保存失败／离线，变更尚未同步”。仅收到服务端保存确认才显示已保存；不可将 localStorage 或画布重绘当作云保存。最新保存作品、未同步本地变更、排队任务各有独立状态。发生错误时标明最近已保存时间和恢复入口。

1. 每次编辑以加载的 revision 为基线。连续拖动或强度滑动先本地预览，操作结束合并一个历史记录，再自动保存。先完成历史记录再发送保存，失败不会清除撤销记录。
2. 路由离开或刷新且有待同步变更，应用内对话框标题“还有未同步的修改”，按钮“保存并离开”“保留本地副本后离开”“继续编辑”。保存失败停留并可选择副本；浏览器关闭仅使用原生 beforeunload 提醒，不承诺自定义文案或强行阻止关闭。
3. 断网保留最近基线和本地操作副本，禁止新的付费任务和云保存成功提示。小程序可能被系统杀死，不承诺长时间后台上传；重新启动展示实际已持久化的恢复副本。敏感提示词默认只在当前会话暂存，长期保存须有清晰偏好。
4. 恢复网络先读取远端。基线一致可同步；409 或远端已变进入 COMMON-04。两栏显示本地副本与远端的时间、跨页变化摘要，不把任意结构自动合并。提供“另存恢复草稿”“打开远端并保留本地副本”“返回比较”；有权限且资源完整才允许在最新基线上重新应用已检查的操作。
5. 历史恢复生成新 revision，保留被恢复前的版本；确认框明确“将以所选快照建立新版本，当前内容仍可在历史查看”。默认至少最近 20 个云恢复快照为建议配置；尚未生成不能伪造。撤销／重做至少 100 次有效操作，在内存预算内，重载后的历史深度如有变化须明确说明，不承诺浏览器永久内存历史。
6. 用户被撤权时立即停止云写入和新链接签发，遮蔽远端内容；允许保留已在本机的未同步副本并说明安全处理，不为其创建未经授权的新云项目。未知同版本字段原样保留；未来 schema 或未知渲染层可读摘要，阻断编辑性的破坏保存及导出，转兼容性说明。

配置草稿、目录和恢复同样使用版本比较。管理员发布冲突展示当前 release 与自己草稿的差异，不能覆盖当前发布指针。恢复草稿不含秘密明文。网络超时不等于提交失败：有幂等键的操作先查询已存在结果；不重新创建第二个订单／任务／兑换／退款。

## 3. 登录、绑定、注销与工作区

WEB-01 / MINI-01：先读已配置登录 capability；网页展示短期一次性微信二维码、剩余有效时间和刷新动作。二维码过期后禁扫码成功推断；扫描与服务端确认分别为“已扫描，请在微信确认”和“正在确认登录”。短信只在已配置并可用时显示，验证码倒计时不代替服务端限流。小程序由平台登录 code 换取会话，不读客户端 OpenID 作为登录凭证，不强索头像／昵称／手机号。

WEB-02：用户先验证当前身份，再验证拟绑定身份；只显示昵称／掩码及渠道，不显示 OpenID。目标已属于另一内部账号时，提示“此身份已关联其他账号，需要验证双方并检查作品与订单归属”，进入受控绑定处理，不按同手机号／昵称静默合并。首期没有安全的跨账号资产合并实现时明确“需支持处理”，不能声称已合并。解绑确认展示将失去的登录方式；不允许移除最后一种有效登录／恢复方式。绑定和解绑成功撤销有关旧会话，要求重登的范围需显示。

WEB-03 / MINI-01：注销先读取本人账号、所有关联区、活动任务、待付／待履约／待退款事项和分享影响。显示“注销后立即退出全部设备，不能再创建任务；照片及派生数据按公示期限删除，依法保留的交易与审计记录限制访问”。具体保留天数取已发布政策；没有政策则禁提交并显示未就绪。存在未结款项、未知生成任务、区归属未处理等阻断时逐项提供处理入口；不能把“等待确认”伪装已取消。通过后重新验证身份，要求用户明确勾选理解影响，再点“确认注销”；二次重复点击复用原申请。成功撤销会话、分享和新任务入口，并展示公开申请号与处理状态访问方式；不得承诺系统无法做到的即时物理删除。不是让 owner 用此入口注销他人。

WEB-04：区切换器总显示当前区名称，交易与生成确认框再次显示归属区；跨区素材移动首期拒绝。创建个人区不会把原来区的订单转移过去。到期或超配额保留已存作品、原片和合法生成结果；限制新上传与新付费任务，提供下载清理，不能悄悄删数据。

## 4. 素材、文件夹与上传

WEB-06 / WEB-07 / MINI-02：目录是逻辑元数据。面包屑、搜索、按名／时间排序、回收站和容量条独立于相册跨页排序。目录名去前后空白，1–80 个 Unicode 码点、NFC＋大小写折叠判同名；禁止斜杠、反斜杠、控制字符、`.` 和 `..`，最多 10 级。名称校验失败就地提示；移动不允许成为自身子孙或跨工作区。

批量移动先显示“将 N 项移至〔目标目录〕”，确认后单次事务；任一项权限／目标／版本失败，显示整批未提交，保留选中项。目录／素材回收先预检子目录数、素材数、引用相册及活动任务数量。确认框“移入回收站”，说明不立即删除云对象；任一引用会破坏完整性时整批禁提交，提供查看引用及单独整理无引用项。恢复同名必须用户改名或选其他父目录，绝不覆盖。

上传选片阶段逐项检查 JPEG／PNG，单图 ≤25,000,000 字节、≤80MP，项目最多 500 照片；不能根据扩展名推断可用。HEIC／RAW／PSD 提示转换；WebP 若未通过兼容验证不接受。状态：待上传→传输中→验证中→可用／已拒绝。传输百分比只代表字节，不代表解码通过；ready 前不进入排版。取消未完成项不删除已就绪原图。配额不足保留已就绪项，剩余项说明原因；批量素材导入不是文件夹移动的原子事务，各项结果须如实可查。

重复检测仅当前工作区；提示“发现相同文件，使用已有素材／仍保留新记录”，不能泄露他区存在与否。不默认发送到 AI；EXIF 时间用于分组先说明，公开预览和成品默认去 GPS。上传凭据过期重新鉴权后续传或重传；仅 adapter 真正支持分片时显示续传，不能假承诺。网页上传若依赖浏览器文件读取，关闭页面会暂停未完成项；服务端已接受的生成／导出任务不受此限制。

## 5. 编辑器、模板与 33 个滤镜

WEB-08：桌面 ≥1280px 为完整工作区，1024–1279px 可收侧栏，<1024px 转只读预览和手机上传入口。顶部固定保存、撤销重做、排版与导出；左素材工具、中画布、右图层属性、底部跨页。页数始终分别显示“内页跨页”和“内页”，如“10 跨页＝20 内页”；封面正背独立、不计内页跨页。

图片、文字、矩形、圆和线支持选择、多选、组／解组、锁定、显隐、复制删除、顺序、对齐吸附、旋转缩放与透明度；100 图层／跨页（含递归）、组深度≤5。锁定图层不能拖动或参与局部重排变更。隐藏图层在图层面板保留并有文字状态。删除跨页确认显示页数和照片引用影响；复制跨页产生独立可变图层，不能改一页连带改另一页。

裁剪双击图片进入，亦有菜单／键盘“编辑裁剪”。只对当前图片显示图框、原图范围和主体／低清警告；cover 默认，contain 可选。图片平移缩放独立于图框。Enter／完成提交为一个操作，Esc／取消还原进入前裁剪。替换照片默认保留图框，重新计算合适裁剪并提示检查；绝不覆盖原片。

文字面板包括字体版本、字号、颜色、粗细、对齐、字距和行距；IME 组合输入期间不抢 Enter 或触发快捷键。溢出、缺字、缺授权字体以图标＋说明标记，可点击定位；换成建议字体必须确认并作为可撤销操作，不自动替换。

滤镜面板把“原图”单列，和稳定 ID F01–F33 分开；名称和配方见 [filters.csv](../../ai-album-v0.1/filters.csv)。不得把原图算作第 34 个滤镜，也不得用 AI 生图代替配方。控件有 0–100% 整数强度、可键盘输入的数值框及可读名称；0% 视觉等于原图，但可保留已选配方。滑动仅预览，释放或数值确认记录一次操作；多照片“应用到所选照片”确认 N 张，将全部配方与强度作为一个撤销操作。没有图片选中、选到文字／形状时禁应用并说明“仅用于图片”；混合选择先标明将只改 N 个图片层。预览使用相同配方版本的低清结果，导出重用不可变版本；配方未发布／资源缺失不假显示可用。

WEB-10：按婚礼／旅行／亲子／写真／国风、尺寸、槽位、权限筛选模板。预览是隔离草稿，展示照片映射、文字替换、未分配项及将改变的跨页范围。用户可来回比较，关闭不会写文档。点击“应用到 N 个跨页”先确认覆盖范围、锁定冲突与授权；不兼容则禁用并提供改变范围／模板。应用成功为一个可撤销事务，旧文档在历史可恢复。预览期间本作品已改变则原预览失效，重新映射；不拿过期映射覆盖用户修改。

## 6. 照片排版、完整性与局部重排

WEB-05 / WEB-11 / MINI-03～04：入口“整理已有照片”与“AI 艺术素材”分开，前者不创建生图任务、不扣生图点数。默认全部使用、每张一次；用户主动更改后才允许筛选或指定重复。自定义顺序不被 EXIF 顺序覆盖。可设置密度、页数、模板版本、必选禁用与锁定；封面和锁定跨页单独说明。

运行前检查可行性：50 张全用、10 跨页最多 2 张应显示“至少需要 25 跨页；增加跨页／提高每跨页上限／明确允许选片”，不自动删掉 30 张。结果返回实际有效候选数，推荐 3 个；不足 3 个如实显示。每个候选展示已用、未用、重复清单、硬约束结果及主体裁剪警告，可逐片定位。漏片、非法重复、越界、锁定改变或清单与真实文档不符的候选禁止应用，评分再高也不放行。

局部重排先选择明确跨页，面板显示锁定照片／图框／文字和保持不变的范围。“应用此方案”仅改选定范围，作为一次撤销；应用前再次核对基线、选片集合和真实候选内容。候选计算不是可靠任务中心的付费生图；若实现仅为当前请求，关闭面板可终止计算且可重新算。只有返回已创建 durable job 后才可承诺切端恢复，不把浏览器内 Promise 说成持久队列。

## 7. AI 创作、同意、报价与结果

WEB-12～13 / MINI-09：仅展示已发布且许可、模型契约、预算和审核标识就绪的风格。初始风格为山水水墨、人像淡彩、花鸟写意的设计目标，未经真实授权样例制作不展示为真实效果。用户只看公开名称、允许模型（如开放）、比例、强度等白名单参数；采购成本、endpoint、bucket、secretRef、供应商诊断只在授权后台。

参考图可选，选入后解释“仅将所选图片用于本次生成，可能改变人物和细节，不承诺人脸一致；请确认你有权处理图中人物”。明确勾选用途同意，记录政策版本与所选素材；拒绝可继续文生图或普通排版。不能把同意默认为全相册／后续训练用途；换参考图、用途或政策需重评有效同意。无权、回收或未就绪图不能选。比例、强度及可选 seed 等仅按模型支持显示，不支持参数不静默忽略。

点击“获取报价”只报价不预占。报价卡显示当前工作区、预设／输出规格、1 张图、本次点数、余额、5 分钟有效倒计时、成功结算／失败释放／未知保留预占的规则和条款；原型不预填真实点数。用户确认“使用 N 点开始生成”才提交；输入、参考、模型、比例或强度变化即清掉旧报价，重新获取。过期、模型停新、预算不足或授权变化时拒绝接受并解释，不能以新价格自动扣点。已接受任务有服务端任务号，生成中可离开、刷新、切端，在任务中心继续查看。

用户态顺序：已接受／排队→生成中→结果检查中（解码、审核、标识）→成功，或失败／取消；提交超时且上游未知显示“确认处理中，点数仍被预占，请勿重复提交”。按服务端冻结规则查询原任务；不是再次扣费重试。运行中取消提示“正在请求取消，最终结果以确认状态为准；若已完成将按成功结算”，不先显示点数已退。终局释放后迟到结果不能重新发布和扣点。用户只看点数预占／结算／释放，不看模型采购成本。

合格结果以私有素材入库，保留生成来源和标识。历史可看创建时间、状态、点数记录、来源、失败原因类别和申诉入口。审核拒绝、坏图或隔离结果不提供插入和公共回显。网页“加入素材”或“插入当前跨页”创建新图片层，不覆盖原片；标题、姓名、日期为独立文字层，改字不重新生图。小程序只能入素材或替换模板允许的照片槽，不新增任意高级图层。已用模板或图层变更导致冲突时先重选位置。换风格是新报价新任务，旧结果不自动删除。

## 8. 导出预检、队列关闭与下载

WEB-14～16 / MINI-06～07：先保存，选择 JPG／PNG／普通 sRGB PDF、页范围、singlePage／spread、72／150／300DPI、尺寸与出血。封面范围独立。展示实际输出像素，不以 DPI 标签假冒清晰度；600×300mm、300DPI、四边3mm出血为 7157×3614px。每输出面≤50MP，超过给降低规格／拆分的明确建议，不静默降质。PDF/X、CMYK、印厂拼版不在首期。

预检绑定保存版本、资源版本和全部输出参数。缺／无权／未就绪原片、字体缺失／无授权、文字超框／缺字、未知 schema／渲染层、非法几何、生成标识缺失、超资源预算均阻断；缩略图不可替代原图。可定位修复后重检。PPI100–199为警告，<100强警告且须明确逐类确认；近安全区／跨中缝警告亦可确认。确认框列出受影响照片和跨页，并说明低清不能保证印刷质量；阻断项无“仍然导出”。

文档／输出参数／资源或配置变化使原预检失效；提交前重检，成功冻结快照与提交时权益。排队期间到期不影响已接受任务。继续编辑产生新 revision，不影响原产物；详情使用“导出的是提交时已保存版本”而非混入最新编辑。

提交成功后给任务号和“可关闭此页，稍后在任务中心查看”。排队／处理／打包／成功／失败／已取消分开；没有进度数据时只显示阶段和等待提示，不伪造百分比与 ETA。取消不是删除任务记录；运行中到取消确认后才终态，成功与取消只能有一个生效。失败按原因提供“回编辑修复”或“按当前设置重新提交”，后者是显式新任务，新预检／权益，原失败记录保留；不能把无限重放作为免费补偿。

下载按当前权限签发短期链接，过期重新鉴权签发；产物本身过期（建议7天，取正式政策）时说明已清理，可在项目资源尚在时新建导出。小程序的图片保存需要相册权限，PDF／ZIP按实际平台文件能力提供预览／转发，系统不支持则诚实说明，不显示虚假“已保存到相册”。导出成功和订阅消息发送成功不同；用户拒绝通知不影响任务，可随时在任务中心查。

## 9. 会员、真实渠道限制、支付与售后

WEB-17～20 / MINI-08：先选当前工作区，显示有效会员天数、权益、点数批次可用／预占／将过期和用量。商品价格与数量只来自已发布 SKU；未确定价格显示“尚未开放购买”，不能用线框示意值冒充生产报价。期限按明确天数展示，续购同档展示起止；跨档折算未确定则不开放。首期没有自动续费，不默认勾选续费或营销同意。素材商用范围看具体许可证，去品牌水印不移除应有 AI 标识。

支付前确认区、商品版本、人民币价格、有效天数、生效方式、退款政策和渠道。WEB-18 显示“支付中／等待服务端确认／正在开通／已开通”；客户端 success 仅查单，不立刻给权益。用户取消支付可返回订单，关闭订单前先查单；若已扣款但履约未完成，保留原订单并提供查单及支持入口，不诱导再次付款。同一事件重复通知不重复开通，页面以订单和履约事实刷新，不靠“支付成功动画”判定。

小程序会员／点数属于数字权益，按服务端 capability 检查主体类目、虚拟支付、iOS／Android、客户端版本、应用商品映射与退款能力。未开通、停用、未配置、降级分别说明；不调用实物 wx.requestPayment 冒充准入，不自行放站外购买引导规避规则。网页渠道独立核验。实际平台资质未接入前，线框购买按钮仅静态示意，不能测试真实扣款。

订单保留收款事实，退款为独立进度。申请先读本单可退款权益／点数、已消费／预占／冻结，展示撤销哪笔 grant、不会影响哪些独立购买。未结任务先取消确认或结算后再计算；不从别的订单点数批次强扣。确认“申请退款”后显示申请中／渠道处理中／已退款／未成功；不得把已提交申请说成到账。正式政策未定时不承诺自动全退；超出自动条件进入支持和人工流程，并遵守适用消费者规则。强制退款遇已消费，记录财务差异不造负余额；前台只展示可理解状态。

兑换输入默认遮挡中段，不持久缓存原始码；提交前确认工作区和将获得的明确权益。无效／过期／已用通用提示，防枚举；网络未知先查幂等结果。成功只发一次并跳权益详情。后台停用仅阻止新兑换，不能无声撤回已合法所得。人工补点、延长、返还和撤销必须专项权限、原因、工单与操作前后摘要。正常渠道退款可由单个有权财务人员完成；对异常人工调整可另启更严的双人复核策略，启用后由另一finance.reviewer复核且禁止自审，不作为首期默认阻断。

## 11. 分享、隐私与能力缺失

项目默认私有；WEB-21 可授权确定范围的成品预览与期限，不能把目录移动当作改变 ACL。确认框显示谁可看、哪些跨页、是否可下载和到期时间。复制的是分享链接而非永久原片 URL。撤销成功立即阻止新的鉴权；已签发直链在最长300秒等正式有效期内可能仍可用，不能承诺追回已下载文件；如业务需即时撤销须启用真正支持的下载网关并在策略中说明。

COMMON-06 先校验分享再取图片，未授权／过期／撤销统一不可用，避免泄露作品名或客户身份。公开成品默认去GPS，生成来源与标识继续保留。COMMON-05 展示协议隐私版本、参考图用途和删除请求入口；不同意生成用途仍可普通排版，通知订阅可拒绝退订，不把多个非必要目的合并为登录条件。

capability 的 available／disabled／unconfigured／degraded 控制每项新操作。未配置云存储可看已有缓存／恢复，但不显示上传成功；未配置 AI 可看旧合法结果但不报价；未配置支付不出现可用购买按钮；字体许可缺失只阻断相关模板／导出。前台只显示通用原因及可行动作，不显示供应商地址、根前缀、密钥引用或采购预算。服务端仍做同样校验，隐藏按钮不能代替鉴权。

## 13. 后台任务、对账、许可、迁移、审计与恢复

ADMIN-23 任务详情：support仅工单关联错误摘要；ops查阶段、尝试、冻结配置和供应商查询摘要；finance只看预占／结算／释放及成本差异；content按权限看审核。记录任务号和请求号，不展示客户完整提示词／原片／支付token。操作“查询上游”“请求取消”“修复后恢复处理”必须专项权限、工单、原因和影响预览。供应商状态未知先查询，不出现“直接再生成”按钮；不能手工设成功绕过可用结果和账本。用户需新任务时先新报价与明确确认。

## 15. 无障碍、键盘与移动边界

页面用真正的button、link、input及heading；图标按钮有具体aria-label（如“将照片旋转90度”，不只“更多”）。保存、上传、任务阶段用aria-live=polite；阻断错误用alert并有文字，颜色不作为唯一编码。正文对比目标≥4.5:1，非文本关键边界≥3:1，支持200%缩放与reduced-motion，不闪烁进度。触控最小44×44px，避免依赖悬停。

弹窗role=dialog、aria-modal、标题关联，打开后焦点进入且Tab圈定，Esc取消（不可中断的已提交动作只关闭展示不撤销服务端事实），关闭回触发按钮；异步完成不突然抢走正在输入的焦点。页面加载不反复读全表；增量状态仅读变化。错误摘要可定位到字段，输入保留，屏幕阅读器可知道未通过的限制。

桌面Ctrl/Cmd+Z撤销、Ctrl/Cmd+Shift+Z重做；Ctrl/Cmd+S请求保存；Delete删除当前可删除选择；方向键1px、Shift方向键10px；Esc退出裁剪／取消当前选择；Tab沿工具、画布代理、属性、跨页导航按视觉顺序走。输入框、IME与原生浏览器快捷键冲突时优先编辑文字；屏幕阅读器使用等价工具按钮。所有拖放操作（排序、移动、裁剪、层级）提供菜单／数字输入／“前移后移”替代。画布不可只靠一个canvas可访问：有可聚焦图层树、可读层类型与状态、属性表单和跨页列表。

小程序用平台可访问组件和明确标签，键盘不假定存在；底部操作避安全区，裁剪双指缩放有缩放滑条替代。高级图层只读说明不打断每次操作。二维码有同等可读登录方式说明，短信备用是否存在由真实能力决定，不能为了无障碍显示未实现服务。导出文件的内容可访问性另需实现验证，本静态稿不声称普通PDF自动具备完整标签结构。

# C2 实际排版导出样片

`layout-export.png` 和 `layout-export.zip` 由浏览器实际执行以下流程生成：导入 3 张原创合成色块图 → 本地 C2 整本排版 → 应用候选 → 完整性及资源预检 → 明确接受低清等预警 → 72 DPI PNG 导出 → 下载。ZIP 包含对应图像与程序生成清单。

这是实际程序输出，不是设计效果图。测试图是 160×100 像素的合成素材，故意用于验证低清预警；不代表摄影样张、AI 生图质量或印刷清晰度。高分辨率 JPG／PNG／PDF 的 C1 程序样片仍见相邻 `program-c1/`。
